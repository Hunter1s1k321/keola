## 🔧 Customization Options

### Musik
Edit path di `index.html`:
```html
<source src="assets/YOUR_MUSIC.mp3" type="audio/mpeg">
```

### Video
Edit path di `index.html`:
```html
<video>
  <source src="assets/YOUR_VIDEO.mp4" type="video/mp4">
</video>
```

### Social Media Links
Edit URL di `index.html` footer:
```html
<a href="https://instagram.com/YOUR_HANDLE" target="_blank">
  <i class="fab fa-instagram"></i>
</a>
```

### Warna
Edit CSS variables di `styles.css`:
```css
:root {
  --dark-pink: #FF69B4;
  --primary-pink: #FFB6D9;
  /* dll */
}
```

## 📞 Quick Troubleshooting

**Musik tidak jalan?**
- Check console (F12) untuk error
- Pastikan file di `assets/`
- Browser mungkin block autoplay

**Video tidak muncul?**
- Verify path di HTML
- Pastikan `keolavid.mp4` ada
- Check file format (harus .mp4)

**Foto tidak load?**
- Check console
- Verify file di `assets/`
- File names case-sensitive

**Website lag?**
- Clear cache (Ctrl+Shift+Delete)
- Kompres media files
- Check file sizes
