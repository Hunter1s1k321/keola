## 🆘 Quick Troubleshooting

**Photos not showing?**
- Make sure in `assets/` folder
- Check file names: keola1.jpg, keola2.jpg, etc.
- Refresh browser (Ctrl+F5)

**Animations stuttering?**
- Compress images smaller
- Close other browser tabs
- Clear cache
- Try different browser

**Cursor glow not visible?**
- Normal on some browsers (Safari)
- Functionality not affected
- Try Chrome/Firefox for best effects
